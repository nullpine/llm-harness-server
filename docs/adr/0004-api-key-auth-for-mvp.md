# ADR-0004: A single shared API key for the MVP

**Status:** accepted
**Date:** 2026-08-25

## Context

The control plane is reachable over the internet on the deployed path, and it
fronts an engine that has no authentication of its own. Something has to
authenticate callers.

The user count is one. The client count is one desktop app. The realistic threat
is not a targeted attacker but the internet's background scanning finding an open
inference endpoint and using the GPU.

Entra ID (or any OIDC provider) would give real identity, revocation, and an audit
trail. It also means a token flow in the desktop app, a redirect URI, key rotation
against a directory, and a login screen — a large amount of surface for a
single-user system, and surface that would have to be redesigned anyway the moment
a second user appeared.

## Decision

**Bearer token, one shared key**, on every route except `/healthz`.

- compared in constant time
- generated by the provisioner (or `dev-local.sh`) and printed once; it lives in
  `.env.local` or `/etc/harness/harness.env`, mode 0600, never in the repo
- scrubbed from every log record by a redaction filter, including the `/admin/logs`
  ring buffer
- on the client it is held by the OS credential store, never leaves the main
  process, and appears in no IPC response or error message
- `/healthz` stays unauthenticated so a monitor can see the service is alive
  without holding a credential

Multi-user identity is post-MVP, and is a *replacement* rather than a layer on
top.

## Consequences

- Rotation is a restart and a re-paste, with no grace period: every client 401s
  until it has the new key. Acceptable for one user; not for ten.
- There is no audit trail beyond request logs, and no per-client revocation.
- The key is only as safe as the transport. HTTPS is mandatory on the deployed
  path; the local path is `127.0.0.1` and does not leave the machine.
- Keeping auth identical on the local and deployed paths is deliberate. It is the
  contract, it keeps the client honest, and it means the local path exercises the
  real code rather than a bypass.
